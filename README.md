# Orbital Dynamics Workshop
During the week of November 9-13, Raul Maldonado, PhD, from the IRyA at UNAM, led a workshop on this topic. The code we developed during those days is hosted in this repository.

## Requisites

- Python 3.10 o higher
- Numpy
- Matplotlib
- Rebound
- Reboundx
- Jupyter
- Marimo (soon)
